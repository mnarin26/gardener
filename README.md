# Merhaba

Mustafa Narin için basit bir Android uygulaması (Kotlin + Jetpack Compose).

- **Paket:** `com.mustafa.merhaba`
- **Min SDK:** 26
- **Target / compile SDK:** 37

## Derleme

```bash
export ANDROID_HOME=/path/to/Android/Sdk
./gradlew assembleDebug
```

Debug APK: `app/build/outputs/apk/debug/app-debug.apk`

## USB ile kurulum (Windows)

Ayrıntılar için proje deposundaki yükleme notlarına bakın (Project store: `docs/android-install.md`).
